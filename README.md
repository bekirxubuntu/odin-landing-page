# Landing Page — The Odin Project

A responsive landing page built using HTML5 and CSS3 (Flexbox) as part of The Odin Project Foundations curriculum.

---

## About The Project

This project is an implementation of a landing page design provided by The Odin Project. The goal was to build the page layout from scratch using semantic HTML5 elements and CSS Flexbox layout techniques.

---

## Built With

* **HTML5:** Semantic structural elements (`header`, `section`, `footer`, etc.)
* **CSS3:** Flexbox layout architecture, custom typography (Roboto), and percentage-based section padding
* **Git & GitHub:** Version control and GitHub Pages deployment

---

## Page Components

* **Header & Navigation:** Flex container housing the brand logo and navigation links.
* **Hero Section:** Main headline, subtext, call-to-action button, and image placeholder.
* **Information Section:** Card grid aligned using Flexbox `gap` and `flex-wrap`.
* **Quote Section:** Customer quote block with right-aligned author attribution.
* **Call to Action Section:** Rounded container with text block and action button.
* **Footer:** Centered copyright section.

## Key Learnings

* **Flexbox Layouts:** Applied `display: flex`, `flex-direction`, `justify-content`, `align-items`, `gap`, `flex: 1`, and `flex-wrap`.
* **Section Layout Strategy:** Utilized percentage-based horizontal padding (`padding: 96px 20%`) to center and bound section content.
* **Component Styling:** Custom borders, `border-radius`, typography hierarchy, and hex color palettes (`#1F2937`, `#3882F6`, `#E5E7EB`, `#F9FAF8`).
* **Git Workflow:** Managed project files and updates with structured Git commits.

## Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/bekirxubuntu/odin-landing-page.git
   ```
2. Navigate to the project directory:
   ```bash
   cd odin-landing-page
   ```
3. Open `index.html` in your browser or launch it using VS Code Live Server.
